# 개발 단계 (roadmap)

작성: 2026-10-26. 진행 상황은 `docs/status.md`, 검증 근거는 `docs/feasibility.md`에 기록한다. 이 문서는 단계 구분과 완료 기준만 다룬다.

## 원칙

- 우선순위: **음성·차량 연동 가능 여부 → 처음부터 끝까지 작동하는 흐름 → 기억 선정 품질 → 화면 완성도 → 선택 기능** (CLAUDE.md 2장).
- 시간 예산: 주당 약 10시간. 1차 접수(11/15)까지 약 30시간, 최종 PT(12/03)까지 약 25시간 추가.
- 실제 입력(REAL)과 데모 입력(DEMO)은 같은 처리 로직을 쓰고 입력만 바꾼다. 데모 결과를 실제 연동 성공으로 보고하지 않는다.

## 0단계. 기술 검증

가장 위험한 가정부터 작은 실험으로 확인한다.

- 녹음 실측: 에뮬레이터 마이크 → `AudioRecord` PCM → WAV 저장 → 재생 (`lab/RecorderLabActivity`).
- Vehicle Gear 조회·콜백을 Virtual Console로 확인. 주행 규제 전환 방법 찾기.
- STT SDK 연결 시도 ("Coming Soon" 상태에서 어떤 실패가 나는지 기록).
- 10/28 설명회 질문: 직접 녹음·백그라운드 녹음 허용 여부, STT·FusedLocation 제공 시기 (`docs/feasibility.md` 끝).

**완료 기준**: 원본 음성·차량 상태 항목이 확인/실패로 기록된다.
**갈림길**: 직접 녹음이 막히면 데모 음성 파일 입력으로 시연하는 쪽으로 방향을 정하고 제약을 문서화한다.

## 1단계. 핵심 처리 로직

화면 없이 단위 테스트 중심으로 만든다.

- `AudioCapture`: 실제 마이크(REAL)·데모 파일(DEMO) 어댑터. 임시 원본은 상한이 있는 파일로 관리.
- `MemoryExtractor`: STT 없이 동작하는 에너지 기반 음성 감지 + 침묵 경계로 약 20~30초 후보 선택 (길이는 실험값).
- `MemoryRepository`: 후보 구간을 독립 WAV로 저장, 메타데이터 기록, 저장 후 원본 만료, 삭제 시 관련 데이터 일괄 제거.

**완료 기준**: 후보 경계가 파일 범위를 넘지 않음, 후보 없음·잡음 입력이 오류가 되지 않음, 삭제한 기억이 재처리로 되살아나지 않음을 테스트로 확인.

## 2단계. 회상·재생 흐름 연결

- `VehicleContext`: 실제 Gear / 데모 상태 분리. `기어 == P` AND `주행 규제 비활성`일 때만 정차로 인정, 불명확하면 제한.
- `RecallPolicy`: 경과 시간·정차·동의·빈도 제한. 데모 시간은 주입한 시계로 바꾼다 (기기 시간 변경 금지).
- 최소 화면: 홈(기록 상태·들을 수 있는 기억), 기억 상세(재생·중지·앞뒤 맥락·삭제), 개발/데모 제어.

**완료 기준**: 입력 → 후보 추출 → 저장 → 회상 판정 → 카드 → 원본 재생 → 삭제가 연결되고, 앱 재실행 후에도 원본 목소리가 재생된다.

## 3단계. 1차 제출 (11/15)

- 시연 영상 촬영. `docs/demo.md`에 재현 순서·데모 출처·실제 연동과의 차이 기록.
- 기획서 문구를 실제 구현 범위와 맞춘다. 미검증 자동 수집을 완성된 것처럼 쓰지 않는다.
- APK 준비 (필요하면 GitHub 정리).

## 4단계. 실제 연동과 예외 처리

- 시작 안내·참여 그룹·동의 화면. 주행 시작 시 참여자 구성 1회 확인.
- 권한 거부·회수, 통화·입력 충돌, 저장 공간 부족, 프로세스 재시작 후 상태 일관성.
- 0단계 결과에 따라:
  - 허용되면 포그라운드 서비스(`microphone`)로 지속 수집.
  - 허용되지 않으면 화면이 보일 때만 수집하고 한계로 문서화.
- STT(`Mode.ON_DEVICE` 고정)·위치는 사용 가능할 때만 붙이는 선택 기능.

## 5단계. PT 준비 (12/03~04)

- 큰 글씨·차분한 한국어 UI로 다듬기. 주행 전환 시 재생 중지 확인.

## 개발 환경 이전 (Windows → Mac, 2026-10-26 결정)

이후 개발은 Mac에서 진행한다. 아래는 이전 후 확인할 항목이며 아직 아무것도 검증하지 않았다.

- 저장소 clone 후 `./gradlew assembleDebug test` 재확인 (JDK는 foojay toolchain이 자동 다운로드).
- `local.properties`(SDK 경로)는 Android Studio가 새로 만든다. 커밋하지 않는다.
- **Pleos Connect Emulator Mac 지원 여부 미확인.** Windows에서 쓴 이미지는 `crp_avd_x86_64`라 Apple Silicon Mac에서 실행되지 않을 수 있다. 공식 문서에서 Mac/arm64 이미지 제공 여부를 먼저 확인하고, 없으면 0단계 에뮬레이터 실험은 Windows PC에서 하거나 설명회에서 대체 환경을 문의한다.
- Mac 내장 마이크로 녹음 실측을 다시 하면 결과에 환경(Mac/Windows)을 함께 기록한다.
